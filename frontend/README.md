# Альфа.Поток — Vue-прототип

Vue 3, Single-File Components и Vite. Прототип перенесён с обычного HTML/JS;
экраны отображаются через Vue-шаблоны, состояние хранится в реактивных объектах.

Требуется Node.js `^22.18.0 || >=24.12.0`.

```powershell
npm.cmd ci
npm.cmd run dev
```

Открыть http://127.0.0.1:5173/ и выбрать один из четырёх готовых профилей.

```powershell
npm.cmd run build
npm.cmd run preview
```

`build` создаёт готовую сборку в `dist/`. Зависимости зафиксированы в `package-lock.json`.

Сохранены главная, продукты, форма заявки, таймлайн, новости, компания,
очередь банка, анализ заявки, переключение темы и мобильное меню.
Демо-решение хранится отдельно для каждой банковской карточки.
Клиентские формы и заявки изолированы между тремя профилями.

Данные и действия пока локальные, без запросов в Django. Изменения сохраняются
только до перезагрузки страницы. Это не действующий кредитный конвейер.
Vite уже настроен проксировать `/api` на Django `http://127.0.0.1:8000`
для следующего этапа интеграции.

Структура: `src/App.vue` — оболочка и состояние, `src/pages/` — экраны,
`src/components/` — общие элементы, `src/data/demo.js` — синтетические данные,
`src/styles.css` — общие стили и анимации. `src/reference.css` — реализация
выбранной первой серии макетов из `docs/design/concepts/01–04`:
главная, продукты, форма и статус заявки. `FinanceArt.vue` анимирует
локальное изображение карты; `AppIcon.vue` содержит общие SVG-иконки.
Графика сгенерирована ImageGen и хранится в `public/images/`.
Промпты и происхождение — `docs/design/assets-prompts.json` в корне проекта.
Внешние шрифты, CDN и удалённые изображения для оформления не требуются.

Анимации: переходы экранов Vue Transition, появление блоков при прокрутке,
движение декоративной карты, отклик кнопок, счётчики сумм и процентов,
фильтрация новостей и обновление таймлайна заявки. Используются Vue и CSS,
без дополнительных библиотек анимации. `prefers-reduced-motion` отключает
движение; декоративная карта останавливается вне экрана и в скрытой вкладке.
