# Защита ITigers

- `ITigers-presentation-v2.pptx` — редактируемая презентация: 8 основных слайдов
  для выступления на 3–5 минут и 2 дополнительных для вопросов.
- `ITigers-presentation.pdf` — версия слайдов для показа и печати.
- `ITigers-defense.pdf` — основная и короткая речь, демонстрация и ответы жюри.
- Редактируемый текст: [docs/DEFENSE.md](../docs/DEFENSE.md).

Открыть PPTX заранее на компьютере выступающего и отрепетировать с таймером.
Шрифт Arial; фактические скриншоты прототипа включены внутрь презентации.
Схема архитектуры и текст редактируются; PDF является визуальной копией слайдов.
Нативное открытие в Microsoft PowerPoint при подготовке не проверялось.

Все данные демонстрационные. Интервью, качество на реальных заёмщиках
и экономический эффект не заявляются. В источниках слайдов указаны файлы
проекта и исходный кейс. Материалы можно использовать без внешнего сервера.
