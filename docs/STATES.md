# Состояния заявки

```mermaid
stateDiagram-v2
    [*] --> DRAFT: сохранить
    DRAFT --> DRAFT: редактирование / вложения
    DRAFT --> SUBMITTED: отправить
    SUBMITTED --> CHECK: валидация
    CHECK --> ENRICH: локальные компания и БКИ
    ENRICH --> SCORING: request_id
    SCORING --> APPROVED: правило Django: низкий риск и достаточный лимит
    SCORING --> REJECTED: стоп-фактор или низкий балл
    SCORING --> REVIEW: пограничный случай или ошибка ML
    REVIEW --> APPROVED: сотрудник + причина
    REVIEW --> REJECTED: сотрудник + причина
    REVIEW --> COUNTER_OFFER: сотрудник + новые условия
    REVIEW --> NEED_INFO: сотрудник + поля или документ
    NEED_INFO --> REVIEW: ответ без изменения финансов
    NEED_INFO --> ENRICH: уточнение финансов
    SCORING --> REVIEW: повторная оценка после дозапроса
    APPROVED --> SIGNING: принять конкретный оффер
    COUNTER_OFFER --> SIGNING: принять новые условия
    SIGNING --> DISBURSED: согласие и демоподпись
    DRAFT --> CANCELLED: отменить
    REVIEW --> CANCELLED: отменить
    NEED_INFO --> CANCELLED: отменить
    APPROVED --> CANCELLED: отказаться / отменить
    COUNTER_OFFER --> CANCELLED: отказаться / отменить
    SIGNING --> CANCELLED: отменить до подписи
    REJECTED --> [*]
    CANCELLED --> [*]
    DISBURSED --> [*]
```

После дозапроса решение всегда возвращается сотруднику, даже если повторный
ML-результат хороший. История, вложения, первоначальные параметры и ответ
сохраняются. Уточняются выручка и текущие кредитные платежи; продукт/сумма/срок
на этом шаге не меняются. Для других условий сотрудник создаёт встречный оффер.

Восстановление: SCORING старше 30 секунд можно повторить через submit;
новый request_id блокирует запоздавший результат предыдущего запуска.
Терминальные результаты не оцениваются повторно. DISBURSED означает только
смоделированную выдачу, повторная подпись возвращает ту же операцию.

Неподходящий статус даёт HTTP 409; чужая заявка/документ — 404, другая роль —
403, невалидные данные — 400. Нельзя произвольно задать status через PATCH.
