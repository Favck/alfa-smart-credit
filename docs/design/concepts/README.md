# Концепты основных страниц

Сгенерировано встроенным ImageGen по запросу владельца проекта.
Это изображения-концепты для обсуждения дизайна, не скриншоты реализации.
Тексты, даты, суммы и условия в макетах демонстрационные и требуют проверки
при переносе дизайна в приложение.

- `01-dashboard.png` — главная кабинета.
- `02-products.png` — каталог кредитных продуктов.
- `03-application.png` — форма заявки.
- `04-status.png` — состояние и путь заявки.
- `05-editorial-dashboard.png` — второй раунд: светлый редакционный дизайн.
- `06-signature-dashboard.png` — второй раунд: выразительный красный блок.

Полный набор использованных промптов сохранён в `prompts.json`.
Промпты второго раунда — в `prompts-v2.json` (встроенный ImageGen).
Графика пока не подключена к Vue-приложению.
